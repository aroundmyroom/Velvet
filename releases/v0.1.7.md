# Velvet v0.1.7 — Album-Art Workshop

Find and fix album covers across the library, with official MusicBrainz / Cover
Art Archive covers first — and the admin always in control of what gets written.

## Album-Art Workshop

- **MusicBrainz / Cover Art Archive is the first art source.** For albums whose
  tracks carry a MusicBrainz release id (from Tag Workshop enrichment), the
  workshop fetches the official front cover from the Cover Art Archive first; only
  when CAA has nothing does it fall back to Discogs → Deezer → iTunes. Releases
  with no CAA art are never shown — they fall through. ~70% of enriched art-less
  albums get an official cover this way.
- **Preview before apply — no more wrong covers stored.** Clicking any cover (the
  big one or a small alternate) opens a **large preview** with **Apply this
  cover** / **Back**. Nothing is written until you confirm.
- **Full undo (Restore).** Every apply snapshots the album's previous art; the
  **Applied** view shows the stored cover with a **Restore** button that reverts
  exactly — folder `cover.jpg` + DB pointers, or removes it if the album had none.
- **Fix a cover (any album).** A dedicated **Fix a cover** mode searches *any*
  album — including ones that already have a wrong cover, which never appear under
  "missing" — shows the current art, and lets you replace it from all sources or a
  manual URL.
- **Seek alternatives for MusicBrainz-only covers.** When an album's only
  suggestion is the official CAA cover, a **Seek alternative covers** button
  queries Discogs, Deezer and iTunes on demand, shows a spinner while searching,
  then lists the alternatives like any other source so you can compare and pick.
- **Bigger, clearer previews in Fix a cover.** Suggestions render as larger tiles
  with a source badge and a hover *Preview* hint, the album's **current cover is
  itself clickable** to open a full-size view, and the search-result thumbnails
  are enlarged — so you can actually see what you're choosing.
- **Source filter, batch apply, MusicBrainz pass.** A source chip row (All · ♪
  MusicBrainz · Discogs · Deezer · iTunes, with counts) filters suggestions by
  provider; **Apply best cover to selected** applies the preferred cover to many
  albums at once; and a MusicBrainz-only pass fetches official covers for every
  album that has a release id.

## Philosophy — detect automatically, apply only on a human decision

The admin keeps total control over what is written to the real library on disk.
The workshop *detects* candidate covers automatically — from a track's MusicBrainz
release id and from targeted searches — but never decides for you. Because the
library is mostly singles, 12-inches and loose songs that will never have album
art, searches produce many plausible-but-wrong results, so every suggestion is
treated as a proposal: it is detected and previewed, but **nothing is written
until someone confirms it is the right cover.**

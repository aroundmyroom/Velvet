# Velvet v0.5.9 — Security & Dependency Update

This maintenance release integrates all seven open Dependabot pull requests,
headlined by a security fix in the passkey stack.

## Security: SimpleWebAuthn v14

`@simplewebauthn/server` is upgraded from 13.3.3 to **14.0.2**, which fixes a
moderate (CVSS 5.4) certificate-revocation vulnerability in passkey attestation
verification ([GHSA-2g3p-m8c9-hhwh](https://github.com/MasterKale/SimpleWebAuthn/security/advisories/GHSA-2g3p-m8c9-hhwh)).

Passkey login and registration are unchanged — v14 has no breaking API changes
for Velvet's usage (the only breaking change is a Node 22+ requirement; Velvet
ships on Node 24). As a bonus, v14 adds support for post-quantum (ML-DSA)
passkey algorithms on capable authenticators.

## Fixed: CI lint gate

A `sonarjs/no-unenclosed-multiline-block` error in the DLNA search-query parser
made the lint check fail on every pull request, which is why the Dependabot
PRs sat red. Fixed — PR CI is green again.

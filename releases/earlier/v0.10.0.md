# Velvet v0.10.0 — Blueprint: reviewed code, hardened security, accurate docs

This release is about the foundation rather than new features. The whole
codebase went through two independent reviews: eight reviewers mapped every
feature and how they connect, about 300 findings were fixed, and a second
review re-checked every fix from scratch. The result is a safer server, a
player that behaves the same everywhere, documentation that matches the code,
and tests that keep it that way.

## Upgrade notes

- **Back up first** (Admin → Backup & Logs). Two small database updates run once on
  the first start: an unused table is dropped and Subsonic "last played"
  times are converted to milliseconds.
- **Sonos now needs the cast permission.** Admins keep access. Turn on
  "Cast" for a user in Admin → Users if they should use Sonos.
- **YouTube, recordings and excluded folders are no longer scanned** as part
  of the library on a full scan. A YouTube folder inside a music folder still
  belongs to that folder.
- **Run "Rebuild Artist Index" once** (Admin → Database) if you use a folder
  in "children only" mode.
- **Passwords** are upgraded to a stronger hash on each user's next login.
  Existing logins keep working.
- **Removed:** Federation (Syncthing sharing, 84 MB of binaries), the RPN/DDNS
  leftovers and the old `/login` page. Old configs that still mention them
  start as before.

## Security

- **Users limited to a sub-folder stay in it.** A path with `..` can no
  longer leave their folder, folder downloads zip only that folder, and every
  library list (search, recent, rated, albums, artists, random songs, Auto-DJ,
  rooms) is limited on the server, not only in the player.
- **Logins can be revoked.** Changing a password signs out every other
  session, and admins can "Log out everywhere" for a user.
- **Narrow, expiring tokens** for Sonos stream links and the jukebox remote
  instead of a full login.
- **Server Speaker** paths are checked against the user's folders and every
  route checks permission.
- **No server crash** from a radio station with an odd redirect. Outgoing
  requests have size and time limits, YouTube downloads refuse private network
  addresses, pairing and passkeys are rate-limited, the server-speaker gain is
  capped, and an open redirect is closed.
- **Backups and exports** are written owner-only, and a failed backup is
  reported instead of silently succeeding.

## Everywhere the same

- **One Auto-DJ.** The TV app and Server Remote now use the server's Auto-DJ,
  the same engine as rooms and Music Assistant radio. Auto-DJ never plays
  audiobooks.
- **Rooms scrobble, count plays and keep statistics** on the server, also
  when no browser is open.
- **The TV app scrobbles** to Last.fm and ListenBrainz; the mobile app sends
  ListenBrainz "playing now"; the Last.fm and ListenBrainz badges show the real
  result.
- **Every app is translated**: the player, admin, mobile app, TV app, Server
  Remote and shared links (about 400 texts that were still English).

## Fixed

- **Scanning no longer holds the database**: ratings, play counts and
  playlists saved during a scan are kept, even when the scan is stopped.
- **Config saves** can no longer overwrite each other or leave a broken file.
- **A play is counted once**, not again when it is scrobbled.
- **Podcasts resume** where you left off, and radio recordings survive a page
  reload.
- **AAC transcoding** works again, transcoding stops when the listener leaves,
  and the mobile app's quality setting works.
- **AcoustID with a wrong key** stops instead of restarting forever;
  **ReplayGain "reset failed"** never removes songs; the **Duplicate Workshop**
  runs in the background and can be cancelled.
- **Player**: the visualizer starts once, crossfade no longer leaves old
  players behind, the audiobook speed menu opens, logging out signs out other
  tabs, passkey sign-in loads your settings, a page refresh never cuts the
  saved queue, and the Listening History view is back.
- **DLNA** serves folders with special characters, and only folders with DLNA
  switched on.
- **Regular users** can set their own Subsonic password and scrobble switches.
- **Deleting a user** removes all their data.
- Plus many smaller fixes; the full list is in `changes-velvet.md`.

## Under the hood

- **Architecture guards in CI.** The test suite (now about 1,580 tests) fails
  when a route is undocumented or documented but gone, code is copy-pasted or
  unused, the database is used outside its layer, a translation is missing, a
  page has inline scripts, a file is sent without a path check, or new
  hardcoded English appears. See `docs/dev/architecture-guards.md`.
- **Clean shutdown**: rooms stop first, then the web server, then the database
  is closed.
- **Background workers** (ReplayGain, BPM, genres, Tag Workshop, AcoustID,
  MusicBrainz) share one controller: they pause during a scan and really stop
  when asked.
- **Shared helpers** replace dozens of copied functions, and about 300 unused
  exports and old features were removed.
- **Documentation** was checked line by line against the code; `docs/API.md`
  lists every route.

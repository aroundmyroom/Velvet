# v0.4.27 — Playing Now Scrobble Status Badges

See live Last.fm and ListenBrainz scrobble status directly in the Playing Now view header.

## Live Scrobble Indicators

The **Playing Now** hero header now displays real-time status badges for **Last.fm** and **ListenBrainz** right next to the "NOW PLAYING" label:

- **Greyed out**: Service is disabled or account is not linked.
- **Orange (Pending)**: Service is linked and active; waiting for the 30-second playback threshold before scrobbling.
- **Green (`✓`)**: Track has been successfully scrobbled to the service.
- **Red (`✗`)**: Scrobble attempt failed (e.g. network error or invalid token).

Hovering over a badge displays a detailed tooltip describing the current state. The badges update automatically when a new song starts, when the 30-second mark is reached, or when connecting/disconnecting accounts in settings.

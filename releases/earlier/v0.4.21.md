# v0.4.21 — Smarter playlist & queue actions

## What's new

A round of quality-of-life improvements to how you add songs to playlists and the queue across Albums, Artists, File Explorer and Search.

### Albums

- **Track click always plays from that track.** Previously, clicking a track when the queue was non-empty appended the entire disc instead of starting playback from the chosen track. This is now fixed — click a track, it plays from there.
- **⋯ per-track context menu.** Each track row has a ⋯ button (hover to reveal) that opens the full options menu: Add to Queue, Play Next, Add to Playlist, Download, Rate, Go to Artist.
- **"+ Add to Playlist" in the album header.** Bulk-add the current disc to any playlist in one click, alongside the existing Play and Add to Queue buttons.

### Artists

- The small `+` button on each song in the artist Songs tab is replaced by **⋯**, opening the same full context menu available everywhere else in the player.

### File Explorer

- Indexed audio files now have an **Add to Playlist** button alongside play / add-to-queue / download.

### Search

- Track rows now display the file format and duration (e.g. `FLAC  4:32`) on the right side, consistent with the File Explorer.

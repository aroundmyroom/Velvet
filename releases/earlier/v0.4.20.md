# v0.4.20 — Duration in File Explorer & Search

## What's new

Audio files in the **File Explorer** and **Search** (Tracks section) now show the song duration next to the file-type badge on the right side of each row.

```
FLAC    4:32
MP3     3:14
WAV     1:02:15
```

The extension and duration are separated by 24 px of space for easy readability. Files that have not yet been indexed (no duration in the database) show only the extension — no regression for unscanned content.

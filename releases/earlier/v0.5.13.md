# Velvet v0.5.13 — Sonos Pause Fix

A follow-up to v0.5.12's Sonos work.

## Pause on the Sonos app updates the player again

v0.5.12 moved Sonos track changes onto live events pushed by the speaker, which
made skips and track changes appear in the player almost instantly. Play and
pause were left behind on the older polling path — and that path was
deliberately slowed down, because live events were expected to cover it.

The result was that pausing from the Sonos app might not show up in the web
player at all: the player bar carried on as though music were still playing.

Transport state now travels on the same live events as everything else. Pausing
or resuming from the Sonos app reaches the player in around a tenth of a second.

## Upgrade note

Restart the server after upgrading, and reload the player in your browser so it
picks up the new client.

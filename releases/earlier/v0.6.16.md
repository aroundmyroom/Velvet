# Velvet v0.6.16 — Maintenance: dependency updates and a follow-redirects security fix

A maintenance release. Nothing changes in how Velvet looks or works.

## Security fix

`follow-redirects`, used under the hood by `axios` and `http-proxy` for
outgoing requests, is updated from 1.16.0 to 1.16.1. That fixes two
high-severity advisories in which credential headers could be passed along
when a request was redirected to another site:

- [GHSA-q3jh-wrc6-jgq8](https://github.com/advisories/GHSA-q3jh-wrc6-jgq8)
- [GHSA-8r9p-f939-6h3c](https://github.com/advisories/GHSA-8r9p-f939-6h3c)

## Dependency updates

- `music-metadata` 12.2.3, `joi` 18.3.0, `file-type` 22.2.0
- Dev tooling and CI: `eslint` 10.13.0, `aquasecurity/trivy-action`

`npm audit` reports no known vulnerabilities after this release.

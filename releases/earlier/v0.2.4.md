# Velvet v0.2.4 — i18n & British English polish

Small quality-of-life release — no new features.

## Theme switcher fully translated

The Velvet / Dark / Light buttons in the player theme pill were hardcoded
English text with no i18n key. All five theme buttons now use
`data-i18n` spans, so the theme names translate correctly in every
language. Dutch users now see **Velvet / Donker / Licht / Hoog contrast /
Kleurenblind** in the switcher.

The High-contrast fallback text was also wrong ("Contrast" instead of
"High contrast") — fixed.

## British English in the English locale

The English locale file contained several American spellings. Corrected
to Cambridge English:

- `"behavior"` → `"behaviour"`
- `"favorites"` → `"favourites"` (Sonos Radio loading / empty state)
- `"Customize"` → `"Customise"` (Home and Shortcuts shelf buttons)
- `"Colorblind"` → `"Colourblind"` (theme label, carried over from v0.2.3)

## Dutch admin theme labels

The admin panel's default-theme dropdown listed **Velvet Dark** and
**Velvet Light** in Dutch instead of **Velvet Donker** and **Velvet Licht**,
inconsistent with the player theme switcher. Fixed.

## Upgrade notes

No action required.

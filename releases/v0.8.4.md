# Velvet v0.8.4 — Security: follow-redirects and minimatch updates

A security patch for two indirect dependencies. Nothing changes in how Velvet
works.

| Package | Severity | From | To | Reached through |
|---|---|---|---|---|
| follow-redirects | high | 1.16.1 | 1.16.2 | axios (outbound requests for metadata, art, radio), http-proxy |
| minimatch | moderate | 10.2.6 | 11.0.5 | archiver (zip downloads, backups), lint tooling |

- **follow-redirects**: custom sensitive headers could be forwarded when a
  request was redirected to another host.
- **minimatch**: a crafted glob pattern could drive a denial of service.
  The fix exists only in the 11 line, so it is pinned through `overrides`;
  zip downloads of folders were checked by hand.

`npm audit` reports no vulnerabilities. All tests pass.

Updating is recommended for everyone, especially Docker users:

```bash
docker pull ghcr.io/aroundmyroom/velvet:v0.8.4
```

# Velvet v0.8.3 — AI DJ: "geen acapella's" means every acapella

## Fixed: a version left out is left out however it is spelled

*"Uptempo disco from the 80s, no acapellas"* still played *New Dimension
(Accapella Version)*, *Chica Cubana (a cappella)* and *Cold Hearted
(Percapella)*. The model understood the request; Velvet then looked for the
literal word "acapella", and real libraries spell it half a dozen ways.

Exclusions ("no …") and wishes ("only instrumentals") now go through
**version words**: each kind of version with the words a listener uses for
it and every spelling it has in titles and file names. Built in:

| Kind | Also catches, for example |
|---|---|
| acapella | a cappella, Acappella, Accapella, Percapella, Dubcapella, vocals only |
| instrumental | Instr., (Inst.), instrumentaal |
| karaoke | backing track, (playback) |
| remix | Rmx), re-mix |
| dub | (Dub Mix), (Club Dub), dub version |
| live | (Live), live version, in concert, unplugged |
| radio edit | radio version, single edit, 7" |
| megamix | mega mix, medley |

The pieces are chosen so they do not catch look-alikes: the band *Cappella*
stays in, *Stayin' Alive* is not a live version, *YRMX2024* is not a remix.
The rule-based reader that takes over when the model is unreachable knows the
families too.

## New: Admin → AI-assist → Version words

The list is editable under the house notes: add a kind, add the spellings
your library uses, remove what does not fit.

- Until you save, the built-in list applies — and a Velvet update may
  improve it.
- Once you save, your list is stored in the config and used as it is. Updates
  never overwrite it, and neither does saving the other AI settings.
- *Back to built-in list* removes your list again. A fresh install starts
  with the built-in list.

## For integrators

`GET /api/v1/admin/ai/version-words`, `POST /api/v1/admin/ai/version-words`
and `POST /api/v1/admin/ai/version-words/reset`; config key
`aiAssist.versionWords`. Details in `docs/API.md`, `docs/ai-assist.md` and
`docs/json_config.md`.

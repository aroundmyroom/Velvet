# v0.4.3

Bugfix: multi-word search queries (e.g. an artist name plus part of the title) still queued songs without a duration, even after the v0.4.1 fix.

## Fixed: cross-field search results still missing duration

The v0.4.1 fix patched the single-column search helper (`searchByX()`), but multi-word queries — where the title and artist words match in different database columns, e.g. searching "Rock the Box Sylvester" — go through a separate cross-field search path (`_crossFieldSearch()`) that builds its own result objects. That path still didn't include `duration`, so songs found this way (a very common case for real-world "artist + title" searches) still queued without a playtime shown. `duration` is now included there too.

## Docker Release

The `v0.4.25` tag triggers the Docker publishing workflow, which builds and publishes the multi-architecture image with both tags:

```bash
docker pull ghcr.io/aroundmyroom/velvet:v0.4.25
docker pull ghcr.io/aroundmyroom/velvet:latest
```

The previous user-facing changes, including the Auto-DJ track-length filter, Sonos synchronization fix, and collapsible sidebar, are documented in `v0.4.24`.

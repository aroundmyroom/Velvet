# v0.4.22 — Album track-click mode toggle

## What's new

A small **Full disc** toggle now appears next to the hint text below every album's track list.

- **Toggle ON** (default): clicking a track loads the entire disc starting from that track — the classic album-listening experience.
- **Toggle OFF**: clicking a track adds only that single song to the queue, leaving everything else untouched.

The hint text updates live when you flip the toggle, so it always tells you exactly what a click will do. The preference is saved per user in `localStorage` and remembered across sessions.

Works for both regular and CUE-sheet albums.

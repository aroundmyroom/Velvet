# Velvet v0.7.3 — Security: body-parser and undici updates

A security release that updates two libraries Velvet depends on. Nothing
changes in how Velvet looks or works. Updating is recommended, especially if
your Velvet is reachable from the internet.

## body-parser 2.4.0

Express uses body-parser to read incoming requests. Version 2.4.0 fixes a
**high-severity denial-of-service** issue: a compressed request with extra
bytes after the body could tie up the server
([GHSA-27r3-jxmh-p828](https://github.com/advisories/GHSA-27r3-jxmh-p828)).

## undici 7.30.1

undici is the HTTP client used by the YouTube downloader. Version 7.30.1 fixes
three issues:

- **High:** a response with an excessive number of content-encodings could
  crash the process
  ([GHSA-xjj6-f33q-929c](https://github.com/advisories/GHSA-xjj6-f33q-929c)).
- **Moderate:** unbounded memory use in the EventSource parser
  ([GHSA-4qv8-2p9j-2685](https://github.com/advisories/GHSA-4qv8-2p9j-2685)).
- **Low:** a Subresource Integrity bypass using upper-case algorithm names
  ([GHSA-f72v-6w45-q472](https://github.com/advisories/GHSA-f72v-6w45-q472)).

After this release `npm audit` reports no known vulnerabilities.

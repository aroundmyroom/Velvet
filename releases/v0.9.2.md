# Velvet v0.9.2 — Equalizer per room and a Home Assistant integration

Two additions for [Velvet Rooms](https://github.com/aroundmyroom/Velvet/blob/main/docs/rooms.md),
the multi-room playback on Sendspin speakers introduced in v0.9.0.

## Equalizer per room

The player's EQ panel now works for rooms. Pick a Velvet Room as the output
and open the equalizer as usual: the panel title shows the room's name, and
every slider, preset and the on/off switch change the room.

- **One EQ per room**, stored on the server. It survives a restart and applies
  whichever browser or speaker app controls the room; two open browsers show
  the same settings.
- **Heard within about a second**, without interrupting the song.
- **Sounds like the browser EQ**: the server uses the same filter curves as
  the browser (measured within 0.2 dB).
- **Never clips.** Boosts are given headroom and a safety limiter catches the
  rest. With strong boosts the room therefore plays a little quieter overall,
  as with a preamp. EQ off or flat leaves the audio untouched.
- **Sonos speakers that follow a room** hear the EQ too.
- The browser's own EQ is unchanged and applies again after
  *Play in this browser*. A line-in is not equalised.

New endpoints: `GET` and `PUT /api/v1/rooms/:id/eq`; the room state carries
`eq`. See `docs/API/rooms.md`.

## Home Assistant integration

Every Velvet Room becomes a media player in Home Assistant.

- **Control:** play/pause, next/previous, seek, volume, mute, shuffle and
  repeat; now playing with artwork; the room's speakers as attributes.
- **Your library in Home Assistant:** artists, albums, playlists, smart
  playlists and recently added appear in the media browser and play straight
  into a room — replace the queue, play next, or add to the end.
- **Voice:** with Assist, "play *album* in the kitchen".
- **No password needed:** Home Assistant shows a code, and you approve it in
  Velvet under *Pair a Device*. A dedicated Velvet user with the Cast
  permission is recommended.

The integration ships in the Velvet repository, so it is released together
with Velvet. Install it through HACS: *Custom repositories*, add
`https://github.com/aroundmyroom/Velvet` as an *Integration*, install
**Velvet**, restart Home Assistant. Each Velvet release then shows up as an
update; keep the integration on the same version as your server. Requires
Home Assistant 2026.2 or newer. Full guide: `docs/home-assistant.md`.

Auto-DJ still tops up a room only while a browser tab with that room is open;
the integration does not change that.

```bash
docker pull ghcr.io/aroundmyroom/velvet:v0.9.2
```

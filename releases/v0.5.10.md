# Velvet v0.5.10 - iOS Player Compatibility

This maintenance release improves compatibility with third-party iOS music
players while preserving the existing browser, Subsonic, and OpenSubsonic
interfaces.

## Encoded library URLs

Media requests now correctly resolve percent-encoded library names. Playback
works from libraries and child libraries whose names contain spaces, including
`Unidisc 12-inch classics`.

The resolution remains constrained to the configured library root and uses the
same access checks as every other media request.

## Accurate bitrate labels

Track metadata now reports bitrate in bits per second, the established API wire
unit. Players that render bitrate in kbps now show accurate values instead of
rounding typical values down to `1 kbps`.

## Upgrade note

Restart the server after upgrading. Refresh the player library or re-add queued
tracks to replace cached metadata with the corrected bitrate value.

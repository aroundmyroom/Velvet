# v0.4.24 — Auto-DJ Track-Length Window

Keep Auto-DJ out of short interludes/skits and long DJ mixes/concert rips by setting a minimum and/or maximum track length.

## Track-Length Filter

A new **Track Length** filter lives in the Auto-DJ settings panel, under Filters, alongside the existing Keyword and Genre filters:

- **Min** and **Max** fields, in minutes — leave either blank for no limit on that side.
- **Include tracks with unknown length** — off by default. Tracks the scanner never read a duration for are skipped unless this is enabled, which is useful on partially-scanned libraries.

Like Minimum Rating, this is a **hard** filter — a track outside the window is never played, even as a fallback. If Similar Artists mode can't find a match within the window, Auto-DJ widens to the full library rather than the artist scope, but the length window itself is never relaxed.

## Server

`POST /api/v1/db/random-songs` accepts two new optional parameters:

| Field | Type | Description |
|---|---|---|
| `minDuration` | `number` | Lower bound of the track-length window, in seconds. |
| `maxDuration` | `number` | Upper bound of the track-length window, in seconds. |
| `allowUnknownDuration` | `boolean` | Default `false`. Include tracks with no scanned duration. |

A backwards window (`minDuration` > `maxDuration`) returns 400.

## Sonos playback synchronization

Fixed a case where Sonos could audibly advance from one track to the next while the Velvet player bar and Recently Played view remained on the previous track.

Velvet casts a lookahead queue so Sonos can play gaplessly without waiting for the browser. If the browser tab is backgrounded or briefly delayed, Sonos may reach a later track first. The player now recognizes matching tracks inside Velvet's own queued window and catches up instead of incorrectly assuming the Sonos app took control. Genuine external navigation still cedes control as before.

## Sidebar cleanup

The left navigation can now collapse to a compact icon-only rail. Hovering an icon shows its translated tooltip, the preference persists per browser, and the main content area gains the reclaimed width.

## Bare-metal / Docker upgrade note

No new dependencies — a plain `git pull` (or pulling the new image tag) is enough. A new `idx_files_duration` index is created automatically on next boot.

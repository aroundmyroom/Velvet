# v0.4.26 — Security Update for qs

This release resolves two moderate denial-of-service advisories in the runtime `qs` query-string dependency used through Express/body-parser.

## Security Fixes

- **CVE-2026-82417 / GHSA-4mjr-xmp4-gh2g** — prevents an attacker-controlled `constructor.isBuffer` value from causing an uncaught exception during a `qs.parse()` / `qs.stringify()` round trip.
- **CVE-2026-82562 / GHSA-x5fp-wj9c-mxmx** — prevents bracket-key comma parsing from bypassing configured array limits and allowing excessive memory allocation.

Both advisories are fixed by upgrading `qs` from `6.15.2` to `6.16.0` through the repository-wide npm override. The lockfile was regenerated and verified with:

```bash
npm audit --omit=dev --audit-level=moderate
npm ci --omit=dev
```

The Docker release workflow publishes the patched multi-architecture image under both tags:

```bash
docker pull ghcr.io/aroundmyroom/velvet:v0.4.26
docker pull ghcr.io/aroundmyroom/velvet:latest
```

# Velvet v0.6.8 — A no-admin-account warning, plus two Proxmox LXC wizard fixes

Three fixes, one of them a genuinely new safety feature in the admin area
itself, not specific to any one install method.

## A persistent warning when no admin account exists yet

Velvet starts in open mode until an account is created — no login required
for anyone who can reach it. That's true whether it was installed with
Docker, bare-metal, or the LXC/Incus wizard, and there was no indication of
it anywhere in the app until now.

The admin area shows a banner on every screen while this is the case:

> No admin account is configured — this instance is open to anyone who can
> reach it. **Create an admin account now.**

It's not dismissible, on purpose — it reflects a real condition, not a tip
to acknowledge once, and it disappears on its own the moment an account
exists. It reuses a flag the server's public ping endpoint already exposed;
the player already checked it internally to decide whether to show a login
screen, but never told a visitor what it found either.

## Proxmox LXC: Advanced Settings was silently dropping NFS/SMB support

Reported from a real install. Choosing NFS or SMB as the music source, then
stepping through the container wizard's Advanced Settings, showed the
"Mount Filesystems" step as empty — and it wasn't just a display glitch:
going through that screen actually discarded the container feature NFS and
SMB mounting depend on. The step reads its starting value from a different
variable than the one the wizard was setting, and unconditionally overwrites
the real setting with whatever it ends up showing. Fixed by setting both,
so the step now shows the correct value from the start and survives the
Advanced Settings flow either way — accepted as shown, or never seen at all
on the quicker Default Settings path.

## Proxmox LXC: the container description showed broken, irrelevant links

Also reported from a real install. The new container's Summary/Notes panel
in Proxmox showed "Sponsoring & Donations" and "Open Script Page" badges —
both pointing at community-scripts.org's own catalog and donation pages.
Velvet isn't part of that catalog, so the script-page link 404'd outright,
and the donation link had nothing to do with this project. Its GitHub link
had the same problem in a quieter way: it silently defaulted to
community-scripts' own repository instead of this one. All replaced with a
single, correct link to `github.com/aroundmyroom/Velvet`, labeled plainly
as not an official catalog entry.

## Verified

The admin banner is confirmed live, through an authenticated request, with
new i18n keys synced across all 12 locale files. The full suite: 304 of
304. The two Proxmox-specific wizard fixes need a real Proxmox host to
verify end to end — the same caveat as the rest of this install path.

# Velvet v0.3.8 — AcoustID diagnostics, NP modal tech info

## AcoustID — diagnostics & error handling

- **Fixed: invalid API key now aborts the worker immediately** with a clear log message instead of silently marking every file as `error`. Previously a wrong key caused the entire library (138k+ files) to be marked as errors with no indication why.
- **Improved logging**: per-file outcomes are now written to the server log — fpcalc failures, API errors (with HTTP status), and successful matches with score. Use `docker logs -f <container> 2>&1 | grep acoustid` to diagnose issues.
- **API link in Admin UI**: the AcoustID settings panel now shows a clickable link to [acoustid.org/new-application](https://acoustid.org/new-application) so users can register an application key directly from the UI.

## Player — Now Playing modal

- **New: technical metadata line** above the star rating shows the audio format, bitrate, sample rate, and channel count — e.g. `FLAC · 1 411 kbps · 44.1 kHz · Stereo` or `MP3 · 320 kbps · 44.1 kHz · Stereo`.

# Velvet v0.2.7 — Performance, Auto-DJ genre guard, directory health check

## Auto-DJ: no more genre lock-in

Auto-DJ is great at following similar artists and BPM flow, but once it drifted
into a tight cluster (Trance, Hardstyle, Italo Disco…) it could stay there
indefinitely — the similar-artist pool for a Trance track is all Trance artists,
BPM and key stay compatible, and nothing pulled the session back.

**v0.2.7 adds a genre memory layer:**

- A rolling window of the last 25 played genres is tracked per session and
  persisted in `localStorage` so it survives a page refresh.
- When the same genre appears **3 or more times consecutively**, Auto-DJ
  requests the next pick with that genre temporarily blacklisted. The escape
  is a single retry — if the server still returns the same genre, the song is
  accepted anyway (no infinite loop).
- After **5 consecutive** same-genre picks, the similar-artist filter is also
  dropped for the escape pick, guaranteeing a way out of deeply locked clusters.
- The same cap applies when any genre exceeds **40 % of the last 25 tracks**
  — even if it wasn't consecutive.
- Users who have set their own genre whitelist in Auto-DJ settings are unaffected
  (the escape would conflict with it).

## Database — query performance

Five new composite indexes improve the hot paths that were doing full-table or
multi-index scans:

| Index | Benefits |
|---|---|
| `idx_files_vpath_ts (vpath, ts DESC)` | Recently Added CTE — covering index scan |
| `idx_files_vpath_year (vpath, year)` | Decade browse, smart playlist year filter |
| `idx_pe_user_hash_started (user_id, file_hash, started_at DESC)` | Per-play lookup (every track) |
| `idx_pe_file_hash (file_hash)` | Artist home-page play stats |
| `idx_pe_started_at (started_at DESC)` | Recent-artists ORDER BY, purge DELETEs |

The old `idx_pe_user_hash` (a prefix of the new 3-column index) was dropped.
All indexes are `CREATE INDEX IF NOT EXISTS` — applied automatically on the
next server start, no data migration.

## Admin — Directory Health Check

A new **"Scan" button** appears in Admin → Directories between the Folder
Structure diagram and the directory list. Click it to check:

- Read and write access to every configured vpath root
- Read and write access to every first-level subdirectory (hidden dirs excluded,
  capped at 300 per path)

Results are shown inline. Each vpath row is clickable to expand — only dirs
with problems are listed; fully-OK subdirs are omitted to keep the view clean.
Vpaths with issues expand automatically.

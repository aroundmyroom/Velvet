# Velvet v0.6.14 — Fix: Docker image now actually ships ffmpeg, yt-dlp, fpcalc and rsgain

A Docker-only fix. Nothing changes for bare-metal, LXC or Incus installs.

The Docker image is meant to come with ffmpeg, yt-dlp, fpcalc and rsgain
already inside it, so a new container is ready straight away. In reality
all of those downloads had been failing silently during the image build.
The base image was installed without `ca-certificates`, so `wget` couldn't
open any HTTPS connection.

Containers kept working, because Velvet downloads any missing tool on
first start. But that first start took several minutes longer than it
should have, and needed internet access to GitHub at that moment.

From this release the image installs `ca-certificates`, and the tools are
inside the image again on both amd64 and arm64 (rsgain on amd64 only, as
before). Just pull the new image:

```
docker pull ghcr.io/aroundmyroom/velvet:v0.6.14
```

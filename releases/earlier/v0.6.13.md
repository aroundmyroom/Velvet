# Velvet v0.6.13 — Maintenance: dependency and tooling updates, fpcalc 1.6.1

A maintenance release that brings Velvet's dependencies and bundled tools
up to date. Nothing changes in how Velvet looks or works.

## Updated libraries

`express` 5.3.0, `nanoid` 6.0.2 and `music-metadata` 12.2.0.

music-metadata is a new major version, so it was checked against 493 real
library files covering every audio format in use. There were no read
errors, and tags, durations, bitrates and cover art all came out exactly
as before. The only difference is that OGG files now report whether they
are lossless, which Velvet doesn't use.

## fpcalc (Chromaprint) 1.6.1

The fingerprinting tool behind AcoustID matching moves from 1.5.1 to
1.6.1. Fingerprints are bit-for-bit identical, so every existing AcoustID
match stays valid. An existing install upgrades its fpcalc automatically
on the next start, and keeps the old one if the download fails. Every
download is checked against a known SHA256 checksum.

**Linux arm64 now gets a bundled fpcalc too.** Chromaprint has published
an official arm64 build since 1.6, so arm64 installs (including the arm64
Docker image) no longer need a system-installed `fpcalc` for AcoustID.

## Docker

- The image ships fpcalc 1.6.1 on both amd64 and arm64.
- Release builds always start from the newest `node:24-slim` base image
  and always fetch fresh yt-dlp, ffmpeg and rsgain, so each image carries
  the latest versions of those tools.

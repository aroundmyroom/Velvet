# Velvet v0.2.5 — Auto-DJ survives refresh; deploy cache-busting; Sonos revert

A reliability release. No new features — three fixes plus a revert.

## Auto-DJ now survives a page refresh

Two things went missing whenever you reloaded the page mid-session:

- **Auto-DJ turned itself off.** The on/off state was being saved to
  `localStorage` but never read back on boot, so every refresh silently
  stopped Auto-DJ. It's now restored after the queue is rebuilt — without
  force-starting playback, so it simply takes over at the end of the current
  track as usual.
- **The Auto-DJ badges disappeared from the queue.** The per-song `_dj`
  marker was being stripped by the queue-compaction whitelist (which keeps the
  saved queue small enough for `localStorage`). `_dj` is now persisted with the
  queue, so the badges stay put across a reload.

## Client deploys now bust the browser cache

The main player's `/` route was rewriting the `app.js` cache-buster to the
plain package version (`app.js?v=0.2.5`), which pinned the URL across content
changes — so a client-only change shipped without a version bump was invisible
until a hard refresh or a restart. It now serves the on-disk **content-hash**
buster (stamped by `sync-webapp-version` on boot), so a changed asset gets a
fresh URL and updates on a normal refresh.

## Sonos casting sync reverted

The v0.2.x Sonos casting-sync rework was reverted. It misread how casting
works — Velvet pushes a multi-track *window* and the Sonos device auto-advances
through it itself — so on a normal track change it tripped the "external
control" detection, paused the web player, stopped syncing, and froze the UI on
the finished song while Sonos kept playing. The previous known-good behaviour is
restored. The original polish issue (the UI clock running slightly ahead of the
speaker) will be re-addressed with a window-following approach and verified on
real hardware before it ships.

## Upgrade notes

No action required. After upgrading, the first load may need one refresh to
pick up the new player bundle.

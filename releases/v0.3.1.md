# Velvet v0.3.1 — Fix purge-orphaned-vpaths 500 and dependency bumps

## Fix

The new `POST /api/v1/admin/db/purge-orphaned-vpaths` endpoint introduced in
v0.3.0 returned a 500 immediately on every call.

`manager.js` is a manual re-export proxy — every function added to
`sqlite-backend.js` must also be forwarded there. The two new functions
(`getOrphanedVpaths`, `deleteOrphanedVpathRows`) were missing from the proxy,
so the runtime hit `undefined` and threw a `TypeError` before the endpoint
logic even started.

Two lines added to `src/db/manager.js`; no other logic changes.

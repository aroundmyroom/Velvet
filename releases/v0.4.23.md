# v0.4.23 — WebAuthn / Passkey Authentication

Sign in to Velvet without a password using biometrics, security keys, or synced passkeys (iCloud Keychain, Google Password Manager, Windows Hello, etc.).

## Sign in with a Passkey

A **"Sign in with Passkey / Phone / QR"** button now appears on the login screen whenever the browser supports WebAuthn. Tap it and authenticate with your face, fingerprint, PIN, or a paired phone — no username or password required.

The button is hidden automatically on browsers that do not support WebAuthn, so existing users see no change.

## User Settings — new dedicated page

A new **User Settings** view is accessible from the sidebar (person icon). It contains two sections:

### Change Velvet Password
Change your own password without needing an admin — just enter the current password and choose a new one.

### Passkeys
Manage your registered passkeys:
- See all passkeys with name, type (synced / single-device), and date added
- **Add Passkey for This Device** — triggers your browser's registration flow; a friendly name is required so passkeys stay identifiable
- **Remove** any individual passkey

The passkey section only appears when the browser supports WebAuthn.

## First-time nudge

After a successful password login, if you have no passkeys yet, a 12-second toast appears with a direct link to User Settings to set one up.

## Admin: passkey management

Admins can view and revoke any user's passkeys from the **Users** modal in the Admin panel (Reset Password section).

## New endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/v1/auth/passkey/auth/options` | Generate WebAuthn authentication challenge (public) |
| `POST` | `/api/v1/auth/passkey/auth/verify` | Verify assertion, issue JWT (public) |
| `POST` | `/api/v1/auth/passkey/register/options` | Generate registration challenge (requires login) |
| `POST` | `/api/v1/auth/passkey/register/verify` | Store new passkey credential (requires login) |
| `GET` | `/api/v1/auth/passkey/credentials` | List own passkeys; admin can pass `?username=x` |
| `DELETE` | `/api/v1/auth/passkey/credentials/:id` | Remove a passkey |
| `POST` | `/api/v1/auth/change-password` | Self-service password change (requires login) |

## Bare-metal upgrade note


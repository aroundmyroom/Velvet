# Velvet v0.5.11 - Faster Browsing Behind Proxies and During Scans

This maintenance release fixes sluggish browsing when Velvet runs behind a
reverse proxy or while a library scan is running on network storage.

## Cached album art

Album art is now served with a one-year immutable cache header. Cover file
names are content hashes, so browsers and proxies keep covers instead of
revalidating each one on every folder view. The "no art" fallback image is
still never cached.

## Non-blocking scanner art checks

The scanner's per-file art checks no longer use synchronous filesystem calls.
They are asynchronous, share one directory read per album folder per scan, and
run with bounded concurrency. The player stays responsive during scans on NFS,
Samba/CIFS and Docker bind mounts. Art detection behaviour is unchanged.

## Upgrade note

Restart the server after upgrading. See `docs/performance.md` for tips on
network-mounted libraries.

# Velvet v0.9.1 — Velvet Rooms: streams with any ffmpeg build

A small fix release for Velvet Rooms, released right after
[v0.9.0](https://github.com/aroundmyroom/Velvet/releases/tag/v0.9.0).

## Fixed

- **Velvet Rooms played nothing with some ffmpeg builds.** ffmpeg versions
  before 7.1 read 5 MB of a raw audio pipe before they produce any output.
  For a live room stream that is more than ten seconds, further ahead than
  Velvet ever sends, so the room stayed silent. Velvet's own ffmpeg download
  was not affected; an older ffmpeg was. The room encoder and the Sonos
  follower stream now tell ffmpeg not to probe the pipe, as line-in already
  did.

Found while adding Velvet to the
[Sendspin conformance matrix](https://github.com/Sendspin/conformance), which
runs Velvet with a static ffmpeg 7.0 build.

```bash
docker pull ghcr.io/aroundmyroom/velvet:v0.9.1
```

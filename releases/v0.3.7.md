# Velvet v0.3.7 — Worker lifecycle fixes

## AcoustID & Normalisation

- **Fixed: workers stop automatically when done** — the AcoustID fingerprinting and ReplayGain measurement workers now exit cleanly once all files are processed. Previously they polled in a 60-second idle loop indefinitely, making the Admin panel show them as perpetually "running" even with nothing left to do. The post-scan hook restarts them automatically when new files are added.
- **Fixed: stuck-at-99% progress** — AcoustID rows frozen as `pending` from a previous server crash are now reset on every server start, so the percentage counter un-sticks without requiring a manual worker restart.

## UI

- Removed the "AI slop" phrase from the login page tagline.

# v0.4.2

Velvet TV (Tizen): File Explorer and an on-screen app version so you can confirm a side-loaded update actually installed.

## New: File Explorer on Velvet TV

The TV app now has a **Files** tab (side menu + Home tile) that browses your library's raw folder structure using the same `POST /api/v1/file-explorer` endpoint the web player uses. Selecting **Files** lists your configured vpaths; drilling into a folder shows sub-folders and playable tracks together, with a focusable breadcrumb trail for jumping back to any parent folder directly. Selecting a track queues every playable file in that folder and starts playback from the one you picked.

## New: app version shown on the Velvet TV sign-in screen

The sign-in screen now shows the installed app version (e.g. `v0.4.2`), sourced from `package.json` at build time. Since Tizen widgets are side-loaded rather than auto-updated through a store, this makes it easy to confirm a freshly side-loaded `.wgt` actually replaced the previous install instead of silently failing.

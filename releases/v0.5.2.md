# v0.5.2 — Library Identity and Scan Reliability

This maintenance release makes large artist libraries steadier and metadata scans less surprising.

## More reliable artist tags

Some files contain artist metadata in a form that metadata readers expose as several values. Velvet now preserves the native artist values instead of silently keeping only the first one. Existing affected files correct themselves when they are rescanned.

## More consistent Artist Library navigation

- Accented and unaccented artist spellings share one internal identity while their displayed names remain intact.
- Canonical artist selection is stable across rescans and runtimes.
- Letter browsing and search use a persisted, indexed sort key, keeping navigation predictable on very large libraries.

No new settings are required. No manual database work is required. The server applies the small schema addition automatically and rebuilds the artist index as needed.

## Upgrade note

Server-side maintenance release — restart after upgrading. A plain `git pull` or the new Docker tag is enough; no full music rescan is required unless you want existing affected metadata rows corrected immediately.

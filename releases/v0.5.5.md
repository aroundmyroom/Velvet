# Velvet v0.5.5 — Playback History and Library Reliability

This maintenance release improves playback history across outputs, broadens
cover discovery, and makes several library and startup paths more reliable.

## Playback history across outputs

Server Speaker playback now records a history event when mpv confirms that a
track has loaded. The event is finalized with the actual played position when
the track completes, is interrupted, the queue is cleared, or mpv stops. The
associated listening session is closed at the same time.

Sonos keeps using the browser's existing wrapped event lifecycle. This means
track changes, pauses, skips, and natural completion remain consistent with
browser playback without creating duplicate history rows from cast requests.

### What clients now see

The browser player, Server Remote, Server Speaker, Sonos output, and other
authenticated playback clients now feed the same user-scoped play ledger.
Consequently, a track played from another client is reflected in the user's
Recently Played list, play counts, play history, Wrapped top songs and artists,
completion and skip rates, listening totals, and Auto-DJ listening history.

The active client remains responsible for its own live controls and position,
while the server records the durable event. Switching clients or closing the
remote page no longer makes the statistics depend on which interface happened
to remain open.

## More cover-art filename support

Album art discovery now recognises `frente.jpg`, `frente.jpeg`, `frente.png`,
and WebP case variants alongside the existing cover, front, folder, and album
names. ZIP and download artwork fallback follows the same convention.

## FFmpeg and library reliability

- Docker startup readiness checks now require both `ffmpeg` and `ffprobe`,
  matching the admin panel's actual readiness criteria.
- Artist and scan paths preserve more metadata reliably, including normalized
  artist identity handling and scanner updates already described in the
  changelog.
- DLNA SQL search and sort helpers are now isolated from the service lifecycle,
  so the SQL safety test exits cleanly after its assertions complete.

## Upgrade note

Server and client maintenance release. Restart after upgrading and hard-refresh
the browser so the synchronized web assets are loaded.

# Velvet v0.6.12 — Fix: play-on-add while paused, LXC docs verified, dependency updates

A small maintenance release: one player fix, a documentation status
update, and a round of dependency updates.

## Adding a song while paused now plays it

If the player was paused and you chose to play a song, Velvet only added
it to the queue and stayed paused, so it looked as if nothing happened.
A paused player is now treated the same as an idle one: the song you
picked starts playing right away.

## Proxmox LXC / Incus install is now verified

The LXC/Incus guide ([`docs/lxc-incus.md`](../docs/lxc-incus.md)) no
longer warns that the installer is untested on real hardware. Both the
install/update script and the container-creation wizard have been run
end-to-end on a real Proxmox VE host across v0.6.1–v0.6.11. That testing
covered privileged and unprivileged containers and both NFS and SMB/CIFS
music sources.

# Velvet v0.5.14 — Real Translations for Ten Languages

This release finishes what the language picker was already promising: German,
French, Spanish, Italian, Portuguese, Polish, Russian, Chinese, Japanese and
Korean are now genuinely translated, alongside a batch of player and Sonos
casting fixes.

## Ten languages, properly translated

Every one of the 12 supported languages already carried the same set of
interface strings, but ten of them were close to entirely untranslated —
English text sitting behind a language selector that implied otherwise.

Each language has now been translated for meaning, not word-for-word: the
wording a native user of a major music app would expect for what a control
actually does, rather than a literal rendering of the English copy. Product
names and technical terms — Velvet, Sonos, Subsonic, Last.fm, ListenBrainz,
Discogs, MusicBrainz, BPM, FLAC, ReplayGain, Auto-DJ and the like — are left
untranslated throughout, the same convention the Dutch translation already
follows.

If your player is set to one of these languages, reload it to see the change.

## Bitrate display fixed

Track bitrate could show as something like "965000 kbps" in the queue panel,
player bar, Playing Now view and Server Remote. The underlying API value is
correct — it reports bits per second — but the display had not been updated
to match and was appending a kbps label to the raw number.

## Vinyl Easter egg: tonearm no longer overshoots

If you've found the hidden vinyl-deck view: the tonearm's needle now stays
within the grooves for the entire track instead of drifting into the run-out
and onto the label before the music has actually stopped.

## Sonos: correct format, quieter logs

Every track cast to a Sonos speaker was announced as MP3 regardless of its
real format, which could send FLAC or WAV files to the wrong decoder. Sonos
is now told the actual format being streamed.

Separately, the ordinary interruptions caused by skipping or seeking while
casting — which Sonos and the browser both do on every track change — no
longer show up in the server log as errors.

## Upgrade note

Restart the server after upgrading, and reload the player in your browser to
pick up the new client and translations.

# Velvet v0.5.8 — Music Assistant Support

Velvet is now a verified **Open Subsonic** music source for
[Music Assistant](https://www.music-assistant.io/), the Open Home Foundation's
music library manager that integrates tightly with Home Assistant.

## What this unlocks

Add Velvet as a music source in Music Assistant and your library plays on
everything MA streams to:

- **Chromecast**, **AirPlay**, **Squeezelite**, Sonos, DLNA players
- **Home Assistant** automations, announcements, and voice control
- MA's own web player and mobile app

## Verified compatibility

The integration was verified against Music Assistant's exact client stack
(py-opensonic). Everything MA's Open Subsonic provider calls passes:

- Library sync: artists, albums, playlists, and the empty-query paginated
  `search3` track sync that trips up some servers
- API-key authentication (recommended), token, and legacy auth
- Streaming, cover art, structured lyrics
- Similar songs (Endless Mix), top songs, recommendations
- Internet radio stations, star/unstar, scrobbling

Setup guide: [docs/subsonic.md → Music Assistant](https://github.com/aroundmyroom/Velvet/blob/main/docs/subsonic.md#music-assistant)

## Fixed: playlist `created` timestamps

The verification uncovered one real spec gap: the Subsonic spec requires a
`created` timestamp on playlist objects, and strict clients (including Music
Assistant) refuse playlists without it. `getPlaylists` and `getPlaylist` now
return `created`/`changed` ISO timestamps, backed by a new column on the
playlists table (silent migration — existing playlists are backfilled once,
new playlists record their real creation time).

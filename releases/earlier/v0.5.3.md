# v0.5.3 — Auto-DJ That Listens

This maintenance release explains and refines one of Velvet's defining ideas: Auto-DJ should make one excellent next decision, not freeze a long future queue against an old song.

## A continuously evolving set

Velvet compares a broad, artist-balanced pool of candidates but commits only one next track. When playback advances, the decision is made again using the new current artist, BPM, key, genre, era, and recent history.

That gives listeners:

- Pairwise continuity from one song to the next
- Filter and library-scope changes that affect the next decision
- Artist and genre cooldowns that advance one selected track at a time
- Instant NEXT through one-track lookahead, without stale future picks
- Graceful behavior when BPM, key, genre, or similarity metadata is incomplete

The README and Auto-DJ scoring guide now document this architecture clearly, including artist-balanced candidate sampling, rolling BPM and era anchors, live key compatibility, genre-drift escape, and the distinction between candidate batches and queue batches.

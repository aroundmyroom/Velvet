# Velvet v0.3.10 — Full OpenSubsonic API compliance

## OpenSubsonic API

- **API Key authentication** (`apiKeyAuth` extension): generate per-user API keys in Admin → Users → Password modal. Authenticate Subsonic clients with `?apiKey=<key>` — no username or password required. Keys do not expire; admins can list and revoke them per user.
- **`reportPlayback`** (`playbackReport` extension): Subsonic clients can report playback state (`started/playing/paused/completed`). A `completed` event triggers a scrobble to Last.fm / ListenBrainz (unless `ignoreScrobble=true`).
- **`getLyricsBySongId`** (`songLyrics` extension): returns embedded lyrics on demand — plain (ID3 USLT, Vorbis LYRICS) and synced (ID3 SYLT). Results cached per content hash.
- **`getSimilarSongs` / `getSimilarSongs2` / `getTopSongs`**: powered by Last.fm, matched against your local library.
- **`startScan` / `getScanStatus`**: Subsonic clients can now trigger a full library rescan and poll real-time scan progress.
- **`getCoverArt ?size=`**: now scales to any requested pixel size (snapped to cache-friendly tiers).
- **Auth error codes 41/42/43**: conflicting/unsupported auth combinations return correct OpenSubsonic error codes instead of a generic auth failure.
- **`getOpenSubsonicExtensions`**: now advertises `apiKeyAuth`, `songLyrics`, `playbackReport`.

## Dependencies

- `nanoid` bumped 5.1.11 → 5.1.16 (random pool corruption fix, forever-loop fix on negative size).
